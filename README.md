# 数据挖掘课程期末项目 星系分类网络

主题：融合多波段观测数据的天体分类与解释分析。数据由SDSS×CatWISE星表和独立Pan-STARRS图像文件元数据构成；分类器只输入14个测光量及W1-W2颜色。元数据用于验收与追溯，未用于预测，不是图像像素网络。

## 交付入口

- docs/课程模板符合性检查与补足报告.md：逐条对照原课程模板，列出原不足、已修订项和待填事实。
- docs/期末报告_星系分类网络.md/.docx/.pdf：正文、可编辑稿和打印稿。
- notebooks/星系分类网络_一键重跑.ipynb：运行入口；源码说明见src/README.md。
- results/review_20261116/submission_validation.json：独立技术检查；results/runs为Notebook运行日志。

## 当前技术结果

融合表1,314,678源、59字段，395分区快照完整、字典与独立验收通过。固定seed=20261112，源级分层5折。2026年11月16日模板复核后，分类已重做：每个外层训练折内部独立抽3万源进行内层3折网格搜索，然后完整训练折拟合；内外层调参源交集为0。RF Macro-F1 0.8171±0.0005，本次完整分类耗时1002.3秒。旧全局开发样本重叠结果已归档，不作为当前结果。

聚类10次真正有放回bootstrap在唯一OOB源上评价，ARI约0.9929；关联规则统一0.05/0.7/>1.1阈值，只留无类别前项、单类别后项的可行动方向，最终14条。补充5维误差切片、6个源级错例、3个留出源SHAP局部解释和13幅图。最终验收以submission_validation.json及工作日志为准。

## 仓库运行边界

本仓库存放报告、课程分析源码、Notebook、13幅图及汇总结果。原始数据、逐源Parquet/预测、模型权重、聊天和历史备份不上传。仓库不是含全部数据的一键复现包：完整计算需要自行在data/raw和data/processed补入授权数据，目录说明见data/README.md。安装依赖后可使用本地项目的verify/recompute/raw入口。报告中的83项检查是完整本地项目的历史验收，未在无数据的仓库副本重跑。

报告为docs/期末报告_星系分类网络.docx及.pdf；模板对照见docs/课程模板符合性检查与补足报告.md。成员姓名、分工比例及真实沟通仍待填写。没有独立测试集，未做天区分块；元数据用于验收，预测只使用测光与颜色。

仓库私有保存，不自动授予研究数据或第三方模板的再分发权。
