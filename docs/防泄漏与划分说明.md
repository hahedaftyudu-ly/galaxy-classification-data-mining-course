# 划分与防泄漏设计

状态：划分已生成并校验，数据治理、分类、聚类与关联规则均已运行。2026-11-16模板复核修订将超参数搜索移到每个外层训练折内部，旧全局开发样本结果已归档。

## 1. 划分对象与主键

- 主表：`data/processed/fused_sources.parquet`，1,314,678 行，一行一个独立 `source_id`。
- 五个波段的 FITS 文件是同一源的不同波段，不拆成五条样本；没有图像增广副本进入本表。
- 因此按 `source_id` 做源级划分即可避免同一源跨折；图像路径属于源的属性，不构成独立样本。

## 2. 固定分层 5 折

- 固定种子：`SEED = 20261112`（`src/config.py`）。
- 方法：按 `class_01` 分层，在每个类别内部用该种子做一次置换，再按位置对 5 取余分配折号；结果写入 `data/processed/folds.parquet`（`source_id, class_01, fold`）。
- 只生成一次，后续治理、调参、评估全部复用同一份折号，不重新抽折。
- 复现命令：

```bash
python3 src/make_splits.py
python3 src/verify_splits.py
```

- 校验记录：`results/splits/fold_summary.json`、`results/splits/fold_verification.json`。校验项包括行数一致、`source_id` 唯一且与主表集合相同、标签未改写、五折齐全、折大小差不超过 3 行、各类别比例与总体偏差小于 1e-5、按种子重算的折号完全一致、逻辑哈希一致、主表哈希与采集记录一致。

## 3. 防泄漏规则

1. **先划分，后变换**：任何依赖目标变量或数据分布的变换（填补、标准化、特征选择、重采样、编码）只在训练折内拟合，验证折只做 transform。
2. **类别权重**只在训练折内按标签分布计算；不使用验证折标签。
3. **缺失值遮蔽实验**：掩码按固定种子在划分之后生成；删除、中位数、IterativeImputer 三种策略共享同一掩码；填补器只在训练折拟合。
4. **超参数与模型选择**：在训练折内部做内层交叉验证或按预先登记的搜索空间选择；不用验证折反复调参。最终报告的是 5 折外推指标（均值±标准差）。
5. **不做目标编码**；分类标签、`source_id`、文件路径、采集时间、文件 mtime、头校验值不作为默认预测特征。
6. **降维/特征选择**（如 PCA、方差/相关性筛选）只在训练折拟合后应用到验证折。
7. **异常值处理**：3σ/IQR 的均值、标准差、分位数只在训练折估计；验证折使用训练折阈值。

## 4. 特征范围

- 默认数值特征：`config.CATWISE_NUMERIC` 的 14 个 CatWISE 测光量（天空背景、背景误差、信噪比、流量、流量误差、星等、星等误差，W1/W2 各一套）。
- 领域派生特征：实际仅使用 `w1mpro-w2mpro` 颜色，共15个预测特征；config中的其他派生公式未进入最终分类器，不申报8个特征的可选项。
- 坐标（`ra, dec`）只用于误差分析和可选的空间稳健性检查，不作为默认预测特征：天区位置既可能代理巡天选择效应，也可能让空间邻源跨折造成乐观偏差。
- 明确排除：`source_id`、`source_name`、`cntr_01`、`partition`、图像/文件路径、`r_mtime_ns`、`r_header_sha256`、`metadata_collected_utc`、`r_metadata_scope`、未采集的头字段。

## 5. 已知限制

- **没有空间分块**：折号按源随机分配，天区上相邻的源可能落在不同折；类星体/恒星的空间分布差异可能带来一定乐观偏差。后续如需要，可按天区（如粗网格或 HEALPix）做分组稳健性检查，并单独报告，不替换主划分。
- 单历元测光：每个源只有一次观测，没有时间序列，因此无法构造有意义的时间窗聚合特征；可选的特征工程第⑥项不按时间窗口径申报。
- 99.24% 的记录为 `file_only`，没有逐源完整 FITS 头；头字段缺失是未采集，不是观测缺失，不参与默认建模。
- 没有独立留出测试集：所有报告指标均为 5 折外推结果；选择与调参必须遵守第 3 节，避免把验证折当测试集反复使用。
- 类别不均衡（GALAXY 约 64%）：搜索时包含类别权重；未申报SMOTE/重采样前后对照的可选项。
