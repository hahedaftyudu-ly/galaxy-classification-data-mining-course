# 无真实缺失时的填补对照方案

状态：实验已执行（2026-11-16），结果与决策见 docs/数据治理报告.md；本文保留原设计。

## 原始数据事实

全表24字段未检出常见缺失标记、NaN或无穷值。不能声称存在真实缺失，也无法从这份完整表判断真实缺失机制。图像抽样存在非有限像素和无FITS文件的目录，应单独分析，不等同于星表测光缺失。

## 基准和模拟场景

保留原始完整数据，另建受控遮蔽实验。先固定按源/必要时按空间组的训练验证测试划分，再生成遮蔽。0%缺失是完整数据基准；5%、10%、20%表示出现一个波段观测组缺失的源比例，而非单元格缺失率。每一情景实际源级与单元格级缺失率均另行报告。

第一阶段用MCAR：按固定种子独立于标签和观测值抽源，再选择W1或W2观测组，所有处理策略共享同一掩码。每源最多遮蔽一个波段组。重复3个预注册种子，例如42、20261111、20261112。

扩展MAR：遮蔽W2的概率依赖保留可见的W1信噪比，阈值与参数仅由训练部分确定。扩展MNAR：遮蔽概率依赖将被隐藏的W2本身真实值；真实值仅供模拟器生成掩码，绝不能供填补器或分类器使用。这些是已知机制的模拟场景，不是原始数据真实机制的判定。

## 防止替代字段泄漏

同一波段的流量、星等、误差、信噪比和相关派生量同步处理；不得遮蔽w1flux却保留由它换算的w1mpro、颜色或缓存表征。先遮蔽原始观测组，再重算颜色/比值等特征。标签、ID不参与填补；坐标是否作为模型输入需在协议中单列，不默认为合理预测特征。

## 三种策略

1. 删除：训练时仅使用完整行；预测端对缺失样本记录无法覆盖，不能悄悄删去后只报较高分数。
2. 中位数：每个训练折估计中位数，验证折只变换。
3. IterativeImputer：仅在训练折拟合，用其他可见特征预测缺失特征；不使用真实标签。输入范围和计算预算在训练阶段确定。

所有方法使用相同划分、遮蔽清单和固定分类器配置。填补器、缩放器及特征选择均放在训练折内。下游模型训练只在用户明确授权的训练阶段执行；本轮只做只读审计和方案存档。

## 评价

- 重建：只在被遮蔽且真实值已知的位置，按字段报告MAE/RMSE，保留各字段单位；删除法无重建值，记不适用。
- 下游分类：Macro-F1、各类召回率、PR指标、相对0%基准的下降。
- 删除法：额外报告保留率、预测覆盖率、各类被删除比例；在共同可预测样本上补充公平比较。不同评价样本上的准确率不得直接排名。
- 资源：耗时、拟合样本数和内存。
- 按相同五折与种子报告均值、标准差；缺失方案只能在开发部分选择，最终测试不用于反复调优。

## 可用于报告的表述

原始星表未检测到显式缺失。为评价观测不完整时预处理方法的鲁棒性，在保持原始数据不变的条件下开展受控遮蔽实验，并在固定划分与共享缺失掩码下比较删除、中位数填补和模型填补。模拟机制及结果与真实数据质量统计分别报告。
